Редакция от 16 ноября 2026 года

Daily Planner — личный инструмент владельца для работы с его расписанием, Google Sheets, Apps Script и виджетом Scriptable. Контакт по вопросам данных: ichukepc@gmail.com.

Какие данные используются

  • Адрес выбранного Google-аккаунта — для идентификации подключения.
  • Содержимое разрешённой Google-таблицы: расписание, повторения, задачи, сведения о занятиях и связанные с ними записи контактов и оплат.
  • Исходники, настройки развёртываний и версии разрешённых Apps Script-проектов — для поддержки, обновлений и восстановления кода.
  • OAuth-данные подключения и отдельный ключ виджета — для выполнения разрешённых запросов.

Разрешения Google Sheets и Apps Script технически выдаются на уровне аккаунта. Рабочие цели планировщика заданы конкретной таблицей и двумя существующими проектами.

Для чего обрабатываются данные

Данные используются для отображения и изменения плана, учёта связанных с занятиями записей, выполнения заданий владельца, проверки работы приложения и доставки обновлений. Подключённый владельцем ИИ-агент может обрабатывать необходимые данные при выполнении этих заданий в выбранной владельцем среде Codex.

Приложение не продаёт данные Google, не использует их для рекламы и самостоятельно не обучает на них модели. Использование и передача информации, полученной через Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

Где хранятся данные

Основные записи находятся в Google Sheets; серверный код и настройки — в Google Apps Script. В рабочей облачной среде могут храниться приватные резервные копии исходников и сведения о развёртываниях. Исходники проекта хранятся в закрытом GitHub-репозитории; токены и выгрузки личных записей в него не добавляются.

OAuth-подключение хранится в личном защищённом поле среды владельца. На iPhone ключ виджета хранится в Keychain приложения Scriptable. Виджет может сохранять локальный снимок плана дня, а загрузчик — текущую и предыдущую версии кода.

Передача и доступ

Данные передаются сервисам, необходимым для выбранных владельцем функций: Google Sheets и Apps Script, его среде Codex и приложению Scriptable. Обработка этими поставщиками также регулируется условиями и настройками соответствующих аккаунтов. GitHub используется для исходников и этих информационных страниц.

Получение данных и кода через шлюз виджета требует отдельного ключа. Публичные информационные страницы не выдают данные таблицы или ключи. На сайте нет формы входа и встроенных скриптов аналитики; поставщик хостинга может обрабатывать технические журналы по своим правилам.

Как отключить доступ и удалить данные

Доступ Google можно отозвать в подключениях Google-аккаунта. Сохранённое OAuth-подключение удаляется из Personal vault и привязок среды Codex; локальный файл входа можно удалить с компьютера владельца.

Для полного отключения виджета владелец удаляет его ключ в настройках шлюза и сохранённое подключение в Scriptable. Локальный кэш данных и кода можно удалить из файлов Scriptable. Сама таблица и её записи сохраняются до удаления владельцем; отключение OAuth не удаляет расписание.

Приватные резервные копии кода сохраняются до удаления владельцем из его среды. По вопросам доступа, исправления или удаления данных можно обратиться по адресу поддержки выше.
